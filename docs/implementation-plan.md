# Prioritized implementation plan

1. Foundation: workspace, design tokens, database, API health, app shell, observability hooks.
2. Identity: auth, sessions, onboarding, profile, localization and entitlements.
3. Trading core: accounts, mock broker, manual trades, MT5 provider boundary, sync jobs.
4. Insight layer: dashboard read model, calendar, analytics and deterministic risk engine.
5. Intelligence: AI coach, structured tools, conversation history and safety controls.
6. Evaluation: challenge rules, certificates, training and progress.
7. Engagement: notifications, achievements, league, leaderboard and rewards.
8. Commercial/admin: billing, plan enforcement, superadmin and audit operations.
9. Production hardening: load tests, accessibility, security review, backup drills and SLOs.
