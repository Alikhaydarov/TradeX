# Initial UI design system

## Tokens

- Background `#080D17`; secondary `#101827`; card `#141E2E`; elevated `#1B293B`.
- Border `#27364A`; primary `#35D6AD`; secondary `#6875F5`.
- Text `#F5F7FB`; muted `#91A0B5`; warning `#F2B65B`; danger `#F16B78`; gold `#D9B978`.
- Radius: 6px controls, 8px cards, 12px dialogs only.
- Spacing follows a 4px grid. Product screens use compact 40px controls and 48px headers.

## Principles

- Dense, calm trading workspace with no decorative blur or floating page sections.
- One global app shell and one vertical scrollbar.
- Skeletons preserve final dimensions; stale data remains visible during refresh.
- Mobile uses a compact top bar and bottom navigation; tables become purpose-built lists.
- Color communicates state, never decoration alone. All state colors include text or icons.
